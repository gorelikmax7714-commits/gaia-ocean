# GAYA — חשבון באוקיינוס 🦄🌊

אפליקציית חשבון לגאיה (כיתה ד׳), בנויה לפי הנושאים שבהם היא צריכה תרגול
במבחן החשבון של תחילת השנה: סדר פעולות, חיבור/חיסור במאונך, כפל ומשמעותו,
חילוק עם שארית, ישר המספרים, בעיות מילוליות, היקף, זוויות ומקבילות, ודיאגרמת עמודות.

הדגש הוא על **הדרך** ולא רק על התשובה: לכל תרגיל יש פתרון מודרך צעד־אחר־צעד,
שיעור קצר עם דוגמה פתורה לכל נושא, דף טיוטה לכתיבה ביד, וחזרה על טעויות.
PWA — עובדת גם בלי אינטרנט.

- **טכנולוגיה:** HTML/CSS/JS בלבד, ללא build. בדיקות: `node --test`
- **סנכרון להורה:** Google Apps Script → Google Sheets (ראו `apps-script/README.md`)
- **ספק ותוכנית:** `docs/superpowers/`
- **עדכון גרסה:** בכל פריסה חדשה יש להעלות את מספר הגרסה ב-`sw.js` (`gaya-v1` → `gaya-v2`) — אחרת הטלפון ימשיך להגיש את הגרסה הישנה מהמטמון
